# vertigo — Windows x64

Отдельное приложение на C# / WPF. Python и ImGui не используются.
Данные игры в комплекте: CS2 build 14197.

## Готовое приложение

Распакуйте **всю** папку приложения и запустите `Vertigo.exe`.
Папка `Data` должна оставаться рядом с EXE. Устанавливать Python или .NET не нужно:
Windows .NET runtime включён в готовую сборку. Первый запуск распаковывает нативные
компоненты runtime в системную временную папку и может занять несколько секунд.

В CS2 выберите окно без рамки / оконный режим и зайдите на карту.
**Не запускайте одновременно старый Python-вариант и Vertigo.**

- INSERT — открыть / скрыть меню.
- END или кнопка × — выход с освобождением удерживаемого ввода.
- Перетаскивание — за заголовок vertigo.
- Прокрутка колёсиком — настройки в колонке под курсором.
- CONFIGS → «Сохранить и скрыть» — сохранить текущие настройки и вернуться к игре.

Aim, RCS, trigger, bhop и strafe по умолчанию выключены: включите нужные переключатели.
Настройки интерфейса, ESP и всех игровых функций независимы.

## Функции

**Aim / RCS.** Выбор головы, шеи или груди; настраиваемый бинд, FOV, плавность,
фильтр spotted mask, удержание цели. RCS имеет отдельные коэффициенты осей,
старт с выбранного выстрела и экспоненциальное сглаживание с сохранением остатка
коррекции. При наведении отдача учитывается в целевом угле, без второй компенсации.
По умолчанию aim требует ПКМ + ЛКМ. RCS использует стрельбу, не бинд aim.

**Trigger.** Удерживайте ALT (можно переназначить). Выстрел при попадании прицела на
живого противника без иммунитета, после настраиваемой задержки. Есть интервал
между выстрелами, фильтры spotted mask и скорости. Союзники исключены независимо
от настройки ESP. Используются обычные события мыши Windows.

**ESP.** Полные/угловые рамки, скелет, контур головы, HP, броня, имя, деньги,
дистанция и опционально союзники. Толщина, непрозрачность, дальность, профиль
скелета. Автовыбор одного из двух распространённых скелетов; если модель
отображается неверно, попробуйте другой профиль. Координаты и длины костей
проверяются; невалидные кости пропускаются. Предпросмотр в меню реагирует на настройки.
Белый цвет означает spotted, серый — отсутствие этой отметки.

**Бомба.** Позиция установленной C4, площадка, время взрыва и разминирования;
для брошенной/переносимой C4 — позиция и расстояние. Таймер не выводится,
если разница игрового времени не проходит проверку.

**Наблюдатели.** Имена клиентов, чья текущая цель наблюдения — локальный персонаж,
в режимах CS2 in-eye / chase. Это данные, доступные клиенту, а не перечень всех
возможных зрителей сервера или трансляции.

**Шаги.** Затухающие кольца при изменении стороны шага в данных движения
бегущего противника на земле. Это эвристика по данным клиента, не анализ аудио.
Удалённые игроки могут не передавать эти поля; в таком случае меток не будет.

**Движение.** По удержанию Space: прыжки при приземлении, боковое управление в
воздухе в направлении взгляда и опциональный автоматический W для разгона на земле.
При выравнивании направления стороны чередуются. На скорости в воздухе приложение
отпускает собственный W, чтобы не мешать боковому ускорению. Если физически держать
W/A/D, ручной ввод тоже влияет на результат. Требуются стандартные бинды движения.
Скорость не записывается в память. Ускорение и тайминг прыжков ограничены физикой сервера;
автострейф и bhop требуют проверки в реальной сессии.

**Интерфейс.** Чёрно-белая тема, прямые углы, верхние вкладки. Ватермарка `vertigo`
с отдельно переключаемыми ником, FPS, часами и картой. FPS — измеренная частота
отрисовки оверлея, не FPS игры. Карта отображается без `de_`, например `vertigo`.
Ник берётся из игры либо задаётся вручную.

**Исключение захвата.** Переключатель использует Windows `SetWindowDisplayAffinity`
с `WDA_EXCLUDEFROMCAPTURE` для меню и оверлея. Это не универсальный обход всех
методов OBS. Проверьте итоговую запись своим методом захвата. Ошибка Windows
показывается для меню; состояние оверлея доступно в диагностике приложения.

## Конфиги и диагностика

Профили: `%LOCALAPPDATA%\Vertigo\configs\*.json`.
Последняя конфигурация — `last.json`; загружается при запуске и сохраняется при выходе.
Журнал: `%LOCALAPPDATA%\Vertigo\vertigo.log`.
Вкладка CONFIGS открывает эти папки/файлы. Профили не включены в распространяемые архивы.

`Vertigo.exe --demo` — предпросмотр с синтетическими данными, без подключения к CS2
и без ввода в игру. Деморежим не перезаписывает автоматически последний профиль.

Чтение памяти — только через ReadProcessMemory; изменения памяти игры не выполняются.
Управление прекращается при потере фокуса, смерти, открытии меню, устаревшем кадре
или ошибке чтения. Ошибка данных отдачи блокирует aim/RCS, но не весь ESP.
При настоящем несовпадении build приложение останавливает чтение до обновления Data.
Случайная замена номера сборки не исправляет оффсеты.

Spotted mask не заменяет проверку стен/дыма. Деньги могут быть неизвестны (`$?`).
Игра может игнорировать SendInput. Защита от обнаружения античитом не реализована.

## Исходники и сборка

Папка исходников содержит проект, C#-файлы и Data, без EXE, bin, obj, конфигов и логов.
Для сборки нужны Windows x64 и .NET SDK 10:

```powershell
dotnet build -c Release
dotnet publish -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true -o publish
```

Проверка (не открывает CS2 и не отправляет ввод):

```powershell
.\publish\Vertigo.exe --self-test --render C:\Temp\VertigoQA
```

`self-test.txt` содержит результат, PNG — отрисованные вкладки и оверлей.
Включены проверки контроллера, конфигов, геометрии и Reader на синтетической памяти
с обеими структурами списка сущностей. Проверены меню и self-contained EXE.
**Реальная CS2 и захват OBS в среде разработки не запускались.**
